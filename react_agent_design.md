## 🛠️ 工具注册表

### Core Tools（核心工具）
| Tool Name | Purpose | When to Use |
|-----------|---------|-------------|
| `analyze_market()` | 分析当前市场数据 | 每个周期开始 |
| `trade(action, qty)` | 执行交易 | 开盘且有明确信号 |
| `reflect(window)` | 反思历史表现 | 每 N 个周期 |
| `create_strategy(spec)` | 创建新策略 | 需要新方法时 |
| `learn_lesson()` | 总结经验教训 | 发现问题/机会时 |
| `reconcile_broker()` | 对账检查 | 定期 |

### Extensible Tools（可扩展工具）
- 系统可以搜索/创建新工具
- 工具使用记录用于优化选择逻辑

## 📊 Reasoning 思维链示例

### 开盘时的 Reasoning：
```
当前观察：
- SPY 价格：750.58
- 持仓：13 股 SPY（买入均价 736.12）
- 账户 PnL：+0.54%
- 策略 tiny-fixed-size-001（已退休）
- 策略 trend-follow-20260611-001（活跃中）

思考：
1. 市场趋势是什么？查看最近价格变化
2. 当前持仓要不要卖？还是继续持有？
3. 有没有更好的策略可用？
4. 历史 lessons 有没有类似情况？
5. Guardian 风险控制怎么样？

结论：
- 选择工具：`analyze_market()` + `trade(HOLD, 0)`
- 理由：当前趋势不明确，先分析再决定
```

### 收盘时的 Reasoning：
```
当前观察：
- 市场已收盘
- 今日有 13 个买入订单，没有卖出
- 有 3 个 no-exploration lessons
- 策略库：11 个策略

思考：
1. 为什么没有卖出？是策略问题吗？
2. 没有探索循环，要不要创建新策略？
3. 从今日交易能学到什么？
4. 要不要优化现有策略？

结论：
- 选择工具：`reflect(50)` + `learn_lesson()` + `create_strategy(...)`
- 理由：需要总结经验，创建更平衡的策略
```

## 🔧 工具创建机制

当系统发现缺少某个工具时：
1. 识别需求："我需要一个能计算 RSI 指标的工具"
2. 搜索现有工具库：`search_tools("rsi")`
3. 如果没有：
   - 请求创建新工具：`request_tool_create("calculate_rsi", purpose="计算 RSI 指标")`
   - 或者生成策略参数：使用 TREND_FOLLOW 策略配置参数

## 📚 知识驱动决策

每个决策都基于：
1. **LESSON artifacts** - 历史经验教训
2. **Strategy metrics** - 策略表现数据
3. **PnL evidence** - 真实盈亏证据
4. **Market state** - 当前市场状态

## 🔄 自我优化循环

1. 使用工具 → 记录结果
2. 分析结果 → 总结 Lesson
3. 应用 Lesson → 改进工具选择
4. 下次决策 → 更明智的选择
