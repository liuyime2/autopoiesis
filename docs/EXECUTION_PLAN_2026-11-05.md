## 0. 目标与边界

项目要证明两件独立的事，再加一个前提：

| 编号 | 目标 | 用什么证明 |
|---|---|---|
| 前提 | 安全可靠：不绕过 Guardian、不重复下单、归因正确、可恢复 | 测试、故障注入、对账 |
| 目标 A | 交易价值：扣成本后，相对同资金同风险基准有增量价值 | 历史样本外实验 + 前向运行 |
| 目标 B | 自进化价值：同数据、同风险、同预算下，LLM 自进化优于固定规则和非 LLM 搜索 | 四组对照实验（A/B/C/D） |

**这份计划能保证的是：每一步都可验证，结论都有证据。它不能保证结果是赚钱。**
“没有找到优势”和 `NOT PROVEN` 都是合法结果，要如实记录，不放宽标准。
到目前为止，173 个信号检验里没有价格方向上的幸存者。

不可变约束：
- 只做 Alpaca 模拟盘。
- 不绕过 Guardian 和开盘检查。
- 不执行 LLM 生成的 shell。
- 不自动放松硬风险限额。
- 模拟盘路径不用伪造数据。
- GPU 5–9 不属于本项目。
- SPY 核心仓上限 $20,000、目标波动率 10%；TLT 只持有不交易。
- 不因研究结果自动增资。

### 对外部审查的三处调整

1. **备份**：外部建议异地加密备份。你 10-14 决定只做本地备份，所以这里只做本地备份和恢复演练。
2. **“未见数据”不存在于历史里**。2016–2026 已被 173 个信号检验和多次核心仓研究看过，不能再当作未见窗口。历史实验只能叫“开发证据”，真正未见的数据只有部署之后的前向数据。
3. **算力是硬约束，外部计划没有估算**。按实测 47 秒每次决策，2016–2026 约 2,700 个交易日：

   | LLM 调用方式 | 一次完整回放耗时 |
   |---|---|
   | 按生产节奏（约 190 周期/天） | 约 6,700 小时，不可行 |
   | 每天 7 个标的各一次 | 约 250 小时，勉强 |
   | 每周一次课程提议（2–6 分钟） | 约 20–55 小时，可行 |

   所以 D 组的 LLM 只负责**每周提议和修改策略**，逐周期执行用确定性规则。LLM 逐周期覆盖规则的价值只在前向 Shadow 里衡量。

## 9. 什么叫“全部完成”

1. G0 到 G5 都有 `acceptance.json`。
2. 目标 A 和 B 各有一个带置信区间的结论，包括可能的 `NOT PROVEN`。
3. 这些结论能由 manifest 复现。
4. 线上系统稳定运行在一个批准的版本上。

如果 G4 的结论是 `NOT PROVEN`：记录失败机制，决定是否调整假设空间再来一轮，不放宽通过标准。
如果连续两轮仍没有增量，就把现实结论写下来：这套系统的价值是风险控制和研究基础设施，而不是 alpha。
