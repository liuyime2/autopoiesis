# 2026-10-24 总结：发生了什么、改了什么、下一步

范围：从 10-24 的第一性原理审查，到 10-24 深夜（美东）。所有数字来自真实运行，出处写在每一项里。
这份总结不是“已达成”的声明：**价格方向上没有找到任何经检验的优势，“赚钱”只能由 60 个有效交易日的 benchmark 来证明。**

## 1. 起点（审查结论）

系统是一个安全、诚实、测量严谨的模拟盘平台，没有被证明的优势来源。基线（10-23 之前）：

| 指标 | 基线 |
|---|---|
| 代理 vs SPY（06-09..10-23） | +0.23% vs +2.80%，落后 2.57 个百分点（`make benchmark`，29 个记录日） |
| 模型对已实现盈亏的贡献 | +$41（10-21）→ −$89（10-23） |
| 研究试验 | 180 次，0 PASS，122 次证据不足 |
| 信号账本 | 173 个检验，6 个 SURVIVES，全部与波动率有关，没有价格方向 |
| 10-15 以来新建策略 | 44 个，其中 38 个 TREND_FOLLOW，12 个建在现金类 ETF 上 |

主要瓶颈：候选空间里没有任何经验证的优势；代理的下单是 1 股试探，盈亏淹没在噪声里。

## 3. 过程中发现并改正的问题（包括我自己的）

- **核心仓第一版有缺陷**：我写了“持仓超过池子就不管”。在 695 天真实 SPY K 线上走真实的循环和 Guardian 重放，
  第一次只成交 1 笔，仓位涨到 $31,200，涨过池子之后它就不再降风险，而那正是最需要降风险的时候。
  同一次重放还发现我没开 `manage_account`（15 次卖出被 Guardian 拒绝）。修正后：52 笔交易，敞口平均
  $14.9k、最高 $20.25k，Guardian 拒绝 0 次，PnL +$5,897 对买入持有池子的 +$12,821，账户最大回撤 2.3%。
  单元测试没抓到这个，重放抓到了。
- **生产代码不能 import 研究包**：我把账本摘要函数放进了研究包，被新克隆里的完整 gate 抓出来（CI 第一次红）。本地 `make check` 不跑这个 class。
- **release 目录切换提交时被未提交的部署记录挡住**，我把 gate 误启在旧提交上；发现后停掉，没有产生记录，已纠正。
- **预注册的空洞条件**：R5 初稿写“死亡比例不高于基线”，而基线是 1.0，永远不会失败。在处理组为空时改成“< 0.8”，并写明。
- **数字要对账**：我最初凭记忆写的“37 个策略 / 36 个 TREND_FOLLOW”与脚本数出来的“44 / 38”不同，以脚本为准。

## 4. 现在的状态与诚实的结论

- 核心仓**已开启**，但它在周一大概率不下单：只读推演显示预测波动率 13.87%（VIX 下限已触发）、目标 18 股，
  账户现有 16 股，差 $1,520，在 $2,000 的容忍带内。它只在波动率明显变化时才调仓。
- 它是**降风险工具，不是 alpha**：在 33 年和重放里，它的收益都低于持有，换来的是回撤减半。
- 价格方向上没有任何经检验的优势（33 年日线、173 个信号测试）。VIX 期限结构也没有可检测的增益。
- **目标“RSI 全自动化赚钱机器”没有达成。** 能证明它的只有 60 个有效交易日的 benchmark（`make benchmark` 记录 29 个日期，
  日报按有效日算是 27/60，口径不同），而且要看的是风险调整后的结果。
