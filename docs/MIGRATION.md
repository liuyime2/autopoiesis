# Migration map

Every path that moved, was deleted, or changed meaning during the infrastructure refactor,
with what replaced it and how to check you are not still depending on the old one.

The refactor followed delete → merge → simplify → reuse → rewrite → add. Nothing here was
kept "for backward compatibility": where an old path survived with a shim, the shim is
listed and so is the date it is expected to go.

## Deleted, with the replacement

| Removed | Why | Replacement | How to check |
| --- | --- | --- | --- |
| `src/voyager_quant/` | 7 files, all `__pycache__/*.pyc`, zero `.py` sources, zero references. Compiled residue of a renamed package. | nothing; the package is `src/min_agent` only | `ls src/` → one directory |
| `auto-fix.sh` | Re-implemented doctor's strategy-library and pidfile checks as inline Python inside a shell wrapper. | `make doctor` (`refused by admission but still selectable`) | `grep -rn auto-fix.sh --include=*.py --include=*.sh .` → hits only inside comments that narrate the deletion |
| `monitor.sh` | Thin wrapper over `--status --doctor --reconcile --evidence-report --ingest-evidence --verify-profit-target`, all of which the CLI provides. | `make status`, `make doctor`, `python -m min_agent.cli --reconcile` | `make help` |
| `observe.sh` | Same flags as `monitor.sh`, with `--utc`. | `make status`, `python -m min_agent.cli --status` | `make help` |
| `run_forever.sh` | Foreground daemon supervisor. `min-agent.service` has `Restart=always` and is `enabled`. | `make run` / `make stop` / `make restart` | `systemctl --user is-enabled min-agent.service` → `enabled` |
| `check-market-open.sh` | Wrote `market-state.json` by calling the broker clock through an inline Python heredoc. | `MarketScheduler.should_trade_now()` / `python -m min_agent.cli --once` | `grep -rn check-market-open .` → no hits |
| `runtime/min_agent/observable-smoke*.{jsonl,json}`, `observable-smoke*/` | Zero references from any code, script or test. Debugging debris. | regenerated by `make smoke` when it needs a scratch dir | `ls runtime/min_agent/` |
| `runtime/min_agent/daemon.out.crashed-1324` | Crash debris from a daemon restart months ago. | nothing | — |
| `auto-fix.log`, `market-check.log`, `ollama.log` | Written only by the two scripts deleted above. Their contents were a banner and a footer. | `runtime/min_agent/daemon.log`, `watchdog.log` | — |

### The two properties that were preserved, not dropped

Deleting `auto-fix.sh` would have removed the only guard on a safety property if the guard
had been the script. It was not:

- **`tools/audit_defects.py`** check `D8` still enforces, over whatever ops scripts remain,
  that no script assigns a risk limit, writes a `lifecycle` field, force-enables a
  strategy, or touches runtime strategy/knowledge state.
- **`tests/min_agent/test_governance.py`** asserts the same three properties
  parameterised over `OPS_SCRIPTS`, which is now `("auto_reviewer.py",)`.

`minictrl` is deliberately *not* in `OPS_SCRIPTS`: it is a service-control wrapper, and
adding it surfaced an assertion about a `DRIFT` marker that only ever applied to
`auto-fix.sh`.

## Added

| Path | What it is | Why |
| --- | --- | --- |
| `pyproject.toml` | Dependency declaration + `min-agent` console entry point | There was no dependency declaration of any kind; the three real dependencies were discoverable only by reading imports, and `pip install -e .` was impossible |
| `ruff.toml` | Lint configuration, every exemption carrying its reason | `make lint` had no tooling, so the `lint` stage of an iteration loop did not exist |
| `README.md` | The entry point: what it does, install, commands, where things are, debugging | There was no README; a newcomer read a 3,756-line chronological debugging log first |
| `docs/ARCHITECTURE.md` | Architecture, execution path, state schema, pre-refactor map | No single document described the system as it is rather than as it was |
| `docs/MIGRATION.md` | This file | The objective requires an explicit old→new map |
| `tests/min_agent/test_syntax_import.py` | 40 tests for the `syntax-import` class | It was the last substantive check class with no test file |

## Changed behaviour

| Change | Was | Now | Why |
| --- | --- | --- | --- |
| `CHECK_CLASSES` | 13 names, described as "the thirteen classes the objective names", never extended | 29 names, every class that runs | Sixteen check classes had been added and ran on every `make verify` while absent from the tuple, so `check_known_classes_run` reported "all 13 classes have tests" while checking 13 of 29, and `classes-list` under-reported by half |
| `check_known_classes_run` | Demanded a test file behind every class | Requires one behind every *behaviour* class; `REPOSITORY_CHECK_CLASSES` names the repository/system checks exempt | The old form could not pass honestly once the tuple was complete. Naming the exemption makes it checkable |
| `syntax-import` in `main()` | In `EXECUTING_CLASSES` but explicitly `continue`d, so its tests never ran | Runs; 47 tests | `test_cli_startup.py`'s "every public name the entry points touch exists" had never executed inside a green gate |
| `EXECUTING_CLASSES` | Contained `defect-regression-audit` and `doctor` | Neither | Both run a bespoke script (`tools/audit_defects.py`, `./minictrl doctor`), not pytest, so the set claimed coverage they did not have |
| `MarketScheduler.sleep_seconds` (closed market) | `min(until_open, max_sleep)` = 900 | `min(until_open, 0.75 × stale_after_seconds)` = 675 | `max_sleep` and `stale_after_seconds` are both 900 and the heartbeat is written once before sleeping, so every night the beat landed exactly on the staleness threshold and doctor reported a live daemon dead |
| `MarketScheduler.__init__` | `(clock_provider=None)` | `(clock_provider=None, stale_after_seconds=900)` | The scheduler needs to know the budget it must stay inside |
| `doctor` python-version check | Removed by me as unreachable under `requires-python` | Restored, with a comment | `test_an_old_interpreter_is_a_failure` was right: this project is run via `PYTHONPATH` with no install step, so nothing but doctor would report an unsupported interpreter |
| `cli.py --verify-profit-target` help | `"the 10% daily paper-profit target"` | `"the 10 percent ..."` | argparse applies `%`-formatting to help strings, so `10% d` parsed as a `% d` conversion and `--help` raised `TypeError` on every invocation. Nothing in the suite called `--help` |
| `tools/alpaca_smoke.py` | `client.get_all_positions()` | `client.list_positions()` | `get_all_positions` has never existed in `alpaca-trade-api` 3.2, so `make smoke` had never run |
| `README.md` risk limits | "not configurable at runtime" | Table of env var + default per limit | All five are read from the environment by `config.py`. I asserted otherwise and the assertion was wrong |
| `test_governance.py::OPS_SCRIPTS` | `("auto-fix.sh", "auto_reviewer.py")` | `("auto_reviewer.py",)` | The deleted script no longer exists; keeping it would have made the parameterisation vacuous |
| `tools/audit_defects.py` check `D8` | Included `check("auto-fix is detect-and-report", "drift_count" in ops["auto-fix.sh"])` | Removed, with the reason recorded | The script it asserted about is gone. The three properties it guarded are still asserted over the ops scripts that remain |

## Unchanged, and deliberately so

| Kept | Why it was tempting to remove it |
| --- | --- |
| `src/min_agent/research/` | 845 lines imported by tests only, and `check_production_research_separation` fails the build if production imports it. That is a correct separation of diagnosis from execution. Wiring it into production to "reduce duplication" would destroy the property |
| `tools/verify.py`'s 30 check classes | Not bloat. Real invariants: production may not import `research/`, every deployed unit's `EnvironmentFile` must resolve, the running daemon's fingerprint must match the worktree, replayed FIFO accounting must reproduce the reported PnL |
| `runtime/min_agent/journal.jsonl` as source of truth | Everything else is derived from it and regenerable |

## If you are following along from the old version

1. `git checkout 02e80c7` is the last commit before the refactor.
2. `git diff 02e80c7..HEAD --stat` shows the whole change.
3. Nothing in the tree references the deleted scripts. `grep -rn "auto-fix\.sh\|monitor\.sh\|
   observe\.sh\|run_forever\.sh\|check-market-open\.sh" --include=*.py --include=*.sh .`
   returns hits only inside comments that narrate why the scripts went - in
   `atomicio.py`, `test_durability.py`, `test_governance.py` and
   `test_governance_invariants.py`. Those are history, not dependencies.
